    body: >-
      On a Mac, to grab a file's full path, right-click it in Finder and then press and hold the Option key. 'Copy' quietly changes to 'Copy [file] as Pathname.' Paste that exact path straight into Terminal, an upload box, or a support ticket, no dragging the file around and no typing the path by hand.
    problem: >-
      You constantly need a file's exact location, for a Terminal command, an upload dialog, or a bug report, but macOS hides full paths by default. Most people resort to dragging the file into a window or typing the path out and getting it wrong.
    breakthrough: >-
      Finder has a hidden modifier: right-click any file, then hold Option. The 'Copy' item transforms into 'Copy [file] as Pathname,' which puts the complete absolute path on your clipboard instantly. It has worked this way for years and almost nobody knows it exists.
    catch: >-
      It only appears while Option is held, so if you right-click and don't press the key you'll never see it. It copies the path as text, not the file itself, so don't use it when you actually mean to copy the file to paste elsewhere.
    forYou: >-
      Next time you need to point Terminal or an upload box at a file, right-click, hold Option, Copy as Pathname, and paste. It's a five-second habit that removes a daily annoyance.
