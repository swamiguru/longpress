Select all the files in Finder, right-click and choose 'Rename [N] Items,' then pick Replace Text, Add a prefix or suffix, or Format to auto-number them (Photo-1, Photo-2 and so on). It takes about 30 seconds and needs zero downloads, and it's perfect for exported screenshots or invoices.
    problem: >-
      Cleaning up dozens of messily named files (screenshots, invoices, exports) one by one is tedious, and most people install a third-party app for something macOS already does natively.
    breakthrough: >-
      Finder has a built-in multi-file rename: select several files, right-click and choose 'Rename [N] Items,' then use Replace Text, Add prefix/suffix, or Format for sequential numbering. No app, no Terminal.
    catch: >-
      It is easy to miss because it only appears when multiple files are selected, and there is no one-click undo for the batch beyond standard Cmd-Z right after, so double-check your pattern before applying it to a big folder.
    forYou: >-
      Next time you export a pile of screenshots or receipts, select them all, right-click, Rename, and use Format to number them cleanly in one shot.
